## ✨ הפיצ׳ר המנצח: עברית בלי להחליף מקלדת

חיפוש טקסט עברי בדרך כלל אומר להחליף פריסת מקלדת הלוך ושוב. **לא כאן.** הקלידו כפי שאתם מבטאים — התוסף מבין תעתיק לטיני *באופן טבעי* ומוצא את העברית:

</div>

![זרימת התעתיק — bereshit מוצא את העברית](https://raw.githubusercontent.com/mgsmath/obsidian-torah-verse-inserter/main/assets/he/translit-flow.svg)

<div dir="rtl">

| אתם מקלידים (מקלדת רגילה) | זה מוצא (עברית) |
|---|---|
| `bereshit` | בְּרֵאשִׁית |
| `shema israel` | שְׁמַע יִשְׂרָאֵל |
| `mayim` | מַיִם |
| `torah` | תּוֹרָה |

התוסף מטפל בחלקים המסובכים: התנועות גמישות, ואותיות דו־משמעיות (יוד, ואו, אלף) מותאמות בחוכמה — כך ש‑`mayim` מוצא מַיִם ו‑`adam` מוצא אָדָם בלי שתחשבו על זה.

כמובן, אפשר גם להדביק או להקליד **עברית ישירות** (עם או בלי ניקוד), או להשתמש ב**מקלדת אלף־בית על המסך** — הבחירה שלכם.

## 📚 מה התוסף עושה

- **מוסיף כל פסוק מהתנ״ך** (תורה, נביאים, כתובים — כל 39 הספרים) לפתק שלכם כציטוט Markdown נקי עם ההפניה.
- **הטקסט העברי המלא כלול, ללא אינטרנט** — מקרא על פי המסורה (מע״מ) במלואו, עם **ניקוד וטעמי המקרא**. הטקסט העברי לעולם לא דורש חיבור.
- **שלוש דרכים למצוא פסוק:**
  1. **לפי הפניה** — `Genesis 1:1`, `bereshit 1:1-3`, `תהלים 23` (שמות ספרים באנגלית, ספרדית, תעתיק או עברית, כולל טווחים)
  2. **בתעתיק** — הקלידו `veahavta` במקלדת הרגילה
  3. **בעברית** — הדביקו בראשית עם או בלי ניקוד
- **תרגומים אופציונליים** — בחרו מהספרייה של ספריא (אנגלית, ספרדית, צרפתית ועוד, משתנה לפי ספר) והם יוכנסו מתחת לעברית.
- **קישורים לעל־התורה** — תיבת סימון אחת מוסיפה קישור שפותח את הפסוק במקראות גדולות (רש״י, רמב״ן, אבן עזרא זה לצד זה).
- **הפורמט שלכם, הכללים שלכם** — עברית עם או בלי ניקוד / טעמים, ציטוט או בתוך השורה.

## 🚀 איך משתמשים

1. **התקינו והפעילו** את התוסף (הגדרות ← תוספי קהילה ← חפשו "Torah" או "Hebrew").
2. פתחו פתק והריצו את הפקודה **"הוספת פסוק (תנ״ך)"** מלוח הפקודות (`Cmd/Ctrl+P`).
   💡 *הקצו לה קיצור מקלדת בהגדרות ← קיצורי מקלדת (חפשו "pasuk").*
3. **חפשו** באחת משלוש הדרכים:
   - הפניה: `shemot 3:14` או `Exodus 3:14`
   - תעתיק: `ehyeh asher ehyeh` *(מקלדת רגילה!)*
   - עברית: `אהיה אשר אהיה`
4. אם תרצו, בחרו **תרגום** מהרשימה ו/או סמנו **קישור לעל־התורה** — שתי הבחירות נשמרות.
5. לחצו **Enter** (או על תוצאה). זהו:

</div>

```markdown
> וַיֹּאמֶר אֱלֹהִים אֶל־מֹשֶׁה אֶהְיֶה אֲשֶׁר אֶהְיֶה...
> — שמות 3:14 · [AlHaTorah](https://mg.alhatorah.org/Full/Exodus/3.14)
```

### מקלדת האלף־בית על המסך

לחצו על כפתור **א** כדי לפתוח מקלדת עברית בתוך חלון החיפוש — שימושי כשרוצים אות מסוימת (כמו ע לעומת א). רחפו מעל מקש כדי לראות את שמו וצלילו. התוסף זוכר אם השארתם אותה פתוחה.

</div>

## 🕮 מקורות הטקסט

- **טקסט עברי:** [מקרא על פי המסורה](https://he.wikipedia.org/wiki/מקרא_על_פי_המסורה) — מהדורה דיגיטלית מדויקת של התנ״ך על פי כתר ארם צובא, בגרסה קבועה דרך ספריא. במקרי כתיב/קרי, התוסף מוסיף את ה**קרי** (הצורה הנקראת), מנוקד במלואו.
- **תרגומים:** לפי דרישה מספריית [ספריא](https://www.sefaria.org.il) (דורש אינטרנט, אופציונלי).
- **קישורי מקראות גדולות:** [על־התורה](https://mg.alhatorah.org).
